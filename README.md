# 📊 Data Visualisation & Dashboard Projects

Welcome to my **Data Visualisation** repository! This repository contains my data analysis, exploratory data analysis (EDA), and dashboard projects created to explore datasets, identify trends, and transform raw data into meaningful insights.

The projects demonstrate my practical skills in data analysis, data visualization, dashboard development, and presenting data-driven insights.

## 📁 Projects

### 1. Appointment No-Show Analysis Dashboard
An analytical project focused on appointment attendance and no-show patterns.

- Explore appointment attendance trends and no-show rates.
- Identify patterns and factors associated with missed appointments.
- Present insights through data visualizations and an interactive dashboard.

### 2. Food Delivery Analytics Dashboard
A dashboard project analyzing food delivery operations and order-related data.

- Analyze order trends and delivery performance.
- Explore order distribution across different areas.
- Identify key metrics and patterns to support business insights.

### 3. Sales EDA and Dashboard
An exploratory data analysis and dashboard project focused on sales performance.

- Perform data exploration and analysis.
- Identify sales trends and patterns.
- Visualize key performance indicators and business metrics.
- Present findings through charts and a dashboard.
